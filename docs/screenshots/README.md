# Screenshots

Place the widget screenshots here with these exact names — the README galleries
(EN + HU) reference them, and they display in filename order:

| File | What it shows |
| --- | --- |
| `01-welcome.png` | The opened widget with only the welcome message. |
| `02-asking.png` | A question typed in, the answer streaming. |
| `03-sources.png` | An answer with the cited **Források** + the 👍/👎 row. |
| `04-feedback.png` | A 👎 vote with the optional "Mi volt a baj?" comment box. |

PNG (or a short GIF reusing the same name) works. Add them on this branch before
merging so the README renders without broken images.
